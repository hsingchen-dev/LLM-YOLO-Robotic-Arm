# LLM-YOLO-Robotic-Arm

## 視覚認識・幾何情報・LLM/VLMを統合したロボットアームの階層型操作システム

**操作対象を選び、遮蔽を判断し、実機の動作へつなぐ。**

本プロジェクトは、従来型の組込みロボットアーム制御を基盤として、画像認識およびLLM/VLMによる高次判断機能を追加した、5自由度ロボットアームの研究プロトタイプです。
ロボットアームの機構、運動学、組込み制御をシステムの中核とし、YOLOによる視覚認識とLLM/VLMによる指示理解・対象選択・遮蔽判断を上位層として統合しています。
LLM/VLMがロボットを直接制御するのではなく、高次判断の結果を座標変換、逆運動学、サーボ制御へ接続することで、複数物体からの対象選択、把持、遮蔽物除去などの実機動作を実現しています。


本READMEでは、**SKYNET-16**の階層構成を中心に、システムの設計、担当範囲、開発の変遷、公開情報の範囲を紹介します。

## 1. 研究のねらい

ロボットアームの操作を、次の三つの問いに分けて設計しています。

1. **何を操作するか。** 自然言語の指示と視覚情報から、操作対象を選択する。
2. **そのまま操作できるか。** 対象物と周囲の物体の位置関係を確認し、遮蔽物の除去が必要かを判断する。
3. **どう動作へ変換するか。** 選択した対象と操作方針を、座標変換・逆運動学を介して実機へ伝える。

研究の中心は、LLMとの対話そのものではなく、**認識・判断・動作をロボットアームの操作として接続すること**です。

初期バージョンでは言語指示と物理動作の接続を検証し、その後、視覚誘導による把持、複数候補からの対象選択、幾何情報を用いた遮蔽判断へと機能を拡張しました。

## 2. 代表デモ：SKYNET-16

**[実演ビデオを開く](https://www.youtube.com/watch?v=7S0SW6Wzqks)**

SKYNET-16では、LLM/VLMを単一のend-to-end制御器として扱わず、対象選択と遮蔽判断に用いる高次の推論要素として組み込んでいます。判断後の動作計算は、座標変換と逆運動学を用いる実行層が担当します。

### Layer 1 — 目標選択と特徴理解

YOLOによる検出結果と画像情報をもとに、物体のカテゴリ、外観的特徴、操作対象としての適切性を扱います。

LLM/VLMには、ユーザーの指示や対象選択の条件を与え、複数候補から操作対象を選択させます。プロンプトによる指示設計を用い、対象と選択理由を明確にすることを目指しています。

### Layer 2 — 幾何情報を用いた遮蔽・障害物判断

対象を選択した後、周囲の物体との位置関係を確認します。この段階では、画像に対する自由な推論だけに依存せず、次の情報を構造化入力として用います。

- 対象物の中心点の被覆関係
- 物体間の相対的位置関係
- バウンディングボックスの重なり

LLM/VLMは、これらの幾何情報と画像情報を参照し、対象物が遮られているか、把持前に遮蔽物を除去すべきかを判断します。

ここで扱うのは、**画像上の関係を利用した遮蔽判断**です。三次元空間における機体全体の衝突検証や、運動経路の安全性保証を示すものではありません。

### Layer 3 — 座標変換・逆運動学による実機実行

選択した対象物または遮蔽物の位置をロボット座標系へ変換し、逆運動学によって関節角度を計算します。その結果を制御層へ渡し、ロボットアームの把持動作または遮蔽物除去動作へ接続します。

この役割分担により、**高次判断の内容と、実機を動かすための計算・制御処理を分けて設計**しています。

## 3. システム構成

### 3.1 認識から実行までの処理フロー

```text
ユーザーの音声／テキスト指示          カメラ画像
             │                          │
             │                   YOLOによる物体検出
             │                          │
             └────────────┬─────────────┘
                          ▼
               LLM/VLMによる対象選択
                          │
                          ▼
          幾何情報を用いた遮蔽・操作方針の判断
                          │
                          ▼
                     座標変換
                          │
                          ▼
                     逆運動学
                          │
                          ▼
              サーボ制御・ロボットアーム動作
```

**Perception → Reasoning → Decision → Execution**

上図は処理の流れを示す概念図です。実装ファイル間の呼び出し順序や、実行後の再観測・成功判定・再試行の詳細をすべて示すものではありません。

### 3.2 Agent-SKYNETの役割

Agent-SKYNETは、自然言語の指示、視覚認識、高次判断、ロボット制御をつなぐモジュール型のソフトウェアエージェントです。

音声またはテキストによる指示を受け取り、LLM/VLMを用いた判断処理と、YOLOによる認識処理、機器との通信、動作実行を連携させます。

本プロジェクトでは、エージェントを「ロボットのすべてを直接制御する一つのモデル」としてではなく、**認識・判断・実行の各モジュールを接続するソフトウェア層**として位置づけています。

### 3.3 上位機・下位機による役割分担

SKYNET-10の開発段階では、上位機と下位機を分離した構成を採用しました。

| 構成要素 | 主な役割 |
| :--- | :--- |
| 上位機 | 音声・テキスト入力、ユーザーインターフェース、YOLOによる画像認識、言語理解・判断処理、システムの統括 |
| 通信 | Socket通信による上位機・下位機間の情報伝達 |
| 下位機：Raspberry Pi | ロボットの運動制御、逆運動学計算、アクチュエータへの指令実行 |
| 実機 | 5自由度ロボットアーム、把持機構、サーボ駆動系 |

認識・対話・判断を担う処理と、実機の動作を担う処理を分け、モジュールごとに開発・調整する構成です。

### 3.4 使用技術とバージョンごとの違い

| 分野 | 使用技術・処理 |
| :--- | :--- |
| 物体認識 | YOLO画像認識、画像上の検出座標・信頼度・外観情報 |
| 高次判断 | LLM/VLM、プロンプト設計、対象選択、遮蔽判断 |
| 出力・通信 | 構造化JSONによる選択結果、Socket通信 |
| 運動学・制御 | 座標変換、逆運動学、サーボ制御 |
| 実機実装 | Raspberry Pi、上位機・下位機の分散構成 |
| 操作インターフェース | 音声認識、音声合成、Streamlit UI |
| 機械・試作 | CAD、SolidWorks、機械設計、プロトタイピング |

 **ロボットアーム制御・逆運動学：** 動作計算とロボット制御部分の開発。
- **YOLOとの統合：** 物体認識結果をロボットの操作処理へ接続。
- **LLMを用いたシステム設計：** 言語理解・高次判断と、認識・制御モジュールを結ぶ構成の設計。
- **プロジェクトの取りまとめ：** 各担当領域を持つメンバーとのチーム開発。

初期バージョンではChatGPTを使用し、SKYNET-10ではローカルLLMとローカル音声処理への移行を扱いました。一方、SKYNET-11・16では視覚情報を扱うLLM/VLMによる判断を紹介しています。

**モデルや音声処理の構成はバージョンごとに区別する必要があります。** SKYNET-11・16の具体的なモデル名、API利用の有無、全体のオフライン動作条件は、本READMEには記載していません。SKYNET-10のローカル化の説明を、すべての後続バージョンに共通する仕様として扱うものではありません。

以下はバージョン順の開発記録です。公開・開発年月が記載されていないバージョンについては、日付を付していません。

### SKYNET-5 — 言語指示と物理動作の接続

**[実演ビデオ](https://www.youtube.com/watch?v=69e78PqmeNM&t=3s)**

簡単な言語指示を理解し、それに応じた物理動作を実行する初期の検証段階です。自然言語とロボットの動作を接続するための基盤を扱っています。

### SKYNET-6 — 対話表現と日本語応答の調整

**[実演ビデオ](https://www.youtube.com/watch?v=lS7rUFcXonQ)**

人間との対話を意識した応答表現や、日本語の敬語への対応を扱うバージョンです。

### SKYNET-6.1 — 音声入力・制御機能の追加

**[実演ビデオ](https://www.youtube.com/watch?v=jr8Sl4M8Fsw)**

音声による入力・制御機能を追加し、ユーザーの発話をロボットの操作へ接続する構成を扱っています。

### SKYNET-8 — 視覚認識と逆運動学による把持

**[実演ビデオ](https://www.youtube.com/watch?v=Eo-8q8rrNC4)**

YOLOによる物体検出と逆運動学を統合し、単純な物体を認識して把持動作へ接続します。言語による指示に加え、画像上の対象位置を利用した操作へ機能を拡張した段階です。

### SKYNET-10 — ローカル処理・UI・分散構成の整理

**[実演ビデオ](https://www.youtube.com/watch?v=zrWmjCPV1bM)**

当該バージョンの開発記録では、次の構成変更を紹介しています。

- **LLMのローカル化：** ChatGPTのクラウドAPIを用いた構成から、軽量なローカルLLMと領域別のプロンプトを用いる構成へ移行。
- **音声処理のローカル化：** ASR・TTSをローカルで処理する構成へ移行。
- **ユーザーインターフェース：** チームで開発したUIにより、設定や操作をまとめて扱う構成を整備。
- **上位機・下位機の分離：** 上位機が認識・対話・判断を担当し、Raspberry Pi側が運動学計算とアクチュエータ制御を担当。

これらはSKYNET-10の構成に関する説明です。応答速度や安定性の改善量を示す測定値は、本READMEには掲載していません。

### SKYNET-11 — 複数物体からの対象選択

**[実演ビデオ](https://www.youtube.com/watch?v=l8yuPjlxAhg)**

複数の検出候補を、ユーザーが指定した選択条件と組み合わせて評価する構成です。

検出対象の座標・信頼度・色情報などを扱い、アノテーション付き画像、JSON形式の検出結果、選択条件を記述したプロンプトをVision LLMへ入力します。

選択条件の例として、「清潔で損傷のない物体を優先する」「画像中心に近い物体を優先する」といったルールや、候補が同順位の場合の判断基準を扱います。

結果は、**対象のラベル、座標、選択理由を含む構造化JSON**として出力します。ここでいう対象選択は、指定条件に基づく判断であり、物理的な把持性能や数学的な最適性を保証するものではありません。

### SKYNET-16 — 目標選択・遮蔽判断・実機実行の階層化

**[実演ビデオ](https://www.youtube.com/watch?v=7S0SW6Wzqks)**

対象選択、幾何情報を用いた遮蔽判断、逆運動学による実行を分けた階層構成です。

LLM/VLMによる高次判断を、ロボット座標系への変換と運動学計算を通じて、把持または遮蔽物除去の動作へ接続します。詳細は本READMEの「代表デモ：SKYNET-16」で紹介しています。
